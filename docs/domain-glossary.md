# Arc domain glossary

Use these terms consistently in product copy, code, and discussion.

| Term | Meaning |
| --- | --- |
| **Life event** | The change or goal that causes a user to seek help, such as starting a first job or considering property. It is expressed in the user’s language. |
| **Intake** | The short conversation that captures the user’s goal, approximate circumstances, timeframe, and uncertainty. |
| **Context** | Facts captured during intake. The user controls which context may be included with a booking request. |
| **Pathway** | Arc’s ordered explanation of which professional types may help, why, when, and what comes next. A pathway is navigation, not regulated advice. |
| **Pathway step** | One professional need within a pathway, with a status, rationale, timing, and next action. |
| **Professional type** | A service category such as financial adviser, mortgage broker, tax accountant, or conveyancer. |
| **Professional profile** | Marketplace information about one fictional provider: speciality, format/location, price, availability, and demo disclosure. |
| **Match** | A professional profile surfaced for the active pathway step using the demo user’s stated needs. |
| **Match rationale** | A plain-language explanation of why a match may suit the user’s context. It must use concrete profile facts and avoid claiming objective superiority. |
| **Your matches** | The personalised marketplace view for the active pathway step. |
| **Browse all** | The general marketplace view, filterable without a generated pathway. |
| **Booking request** | The demo action that records a chosen professional, time, and approved context. It is not a real appointment or payment. |
| **Navigation guidance** | Arc’s explanation of professional roles, sequence, and questions to resolve. |
| **Regulated advice** | Personal financial, credit, tax, or legal advice that Arc does not provide; the relevant qualified professional provides it. |
| **Demo state** | Versioned local browser data used to keep the scripted journey consistent and resettable. |
